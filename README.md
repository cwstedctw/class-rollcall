# 課堂點名網頁

老師把 QR 投影在螢幕上，同學用手機掃一下就簽到。這是東華「和AI一起寫程式」這門課真的在用的點名工具，2026-11-23 第一次在課堂上用。

這個 repo 是它的原始碼。你可以把它抓回自己的電腦跑起來、改它，再把你的修改送回來。被收下的修改會放進全班實際在用的那一版。

## 它怎麼運作

1. 老師開老師頁，選課、按「開始點名」。螢幕出現 QR 和一組 6 碼，QR 每隔幾十秒換一次。
2. 同學掃 QR（或開網址輸入 6 碼），用學校的 Google 帳號簽到。
3. 成績簿裡今天那一欄存在、而且整欄是空的，這一場就會即時寫入：同學掃完幾秒內，他那一格變成 1。這件事是老師頁在背景做的，老師頁要開著才會寫。
4. 老師按「結束點名」，或老師頁開著的時候時間到了，程式結算這一場，把沒簽到的人填成 0。格子裡如果已經有 0、1 以外的內容（例如「請假」），程式不會蓋掉。

畫面上的字都是中文和英文並列。

正式版跑在 Google Apps Script 上，資料存在 Google 試算表。

## 在自己的電腦跑起來

需要 Node.js 22 以上，不用裝任何套件，也不需要 Google 帳號。在終端機打 `node -v`，看到 `v22` 或更大的數字就可以。

```bash
node apps-script/dev/serve.mjs
```

終端機印出一行老師頁的網址，才算啟動成功；把那個網址貼到瀏覽器打開。這是本機預覽版：課程和名冊都是假的（8 位假學生），重開就還原，怎麼玩都不會弄壞任何東西。

想同時扮學生，另開一個分頁：

```
http://127.0.0.1:8918/?user=S0000002%40gms.ndhu.edu.tw
```

輸入老師頁上的 6 碼，就會看到老師頁的簽到人數加一。

## 跑測試

```bash
node --test "apps-script/dev/*.test.mjs"
```

現在有 63 條測試，最後幾行會寫 `pass 63`、`fail 0`。你改完程式之後再跑一次：全過表示這些測試檢查到的行為都還是對的。測試沒檢查到的地方，要自己在預覽版看過。

## 檔案在哪裡

| 檔案 | 是什麼 |
| --- | --- |
| `apps-script/Logic.gs` | 規則：6 碼怎麼產生、誰算遲到、學號怎麼從信箱取出來。不碰 Google，最好讀 |
| `apps-script/Code.gs` | 流程：開場、簽到、結束、寫進成績簿 |
| `apps-script/Teacher.html` | 老師頁的畫面 |
| `apps-script/Student.html` | 學生頁的畫面 |
| `apps-script/QrLib.html` | 畫 QR 的函式庫（別人寫的，不用改） |
| `apps-script/dev/serve.mjs` | 本機預覽的小伺服器 |
| `apps-script/dev/gasfake.mjs` | 假的 Google：讓程式在你電腦上以為自己在 Google 裡 |
| `apps-script/dev/*.test.mjs` | 測試 |

第一次讀建議從 `Logic.gs` 開始，只有不到三百行。

## 你改的東西會去哪裡

這個 repo 跟正式版是分開的。你的修改被合併進這裡之後，老師會再看過一次，才放上正式版。也就是說，在這裡做實驗不會影響任何人的點名紀錄。
